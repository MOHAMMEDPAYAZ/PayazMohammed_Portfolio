# Payaz Mohammed: Portfolio

Personal website of Payaz Mohammed, Database Administrator at Connex Credit Union and PhD student in Artificial Intelligence at the University of the Cumberlands, researching explainable, fair AI for credit unions.

**Live site:** https://mohammedpayaz.github.io/PayazMohammed_Portfolio/

## About this site

- A single `index.html` file: no build step, no dependencies.
- Hosted free on GitHub Pages.
- To add a photo, upload a square image named `profile.jpg` to the repository. Until then, the site shows initials.
